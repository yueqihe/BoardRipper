# 使用指南

BoardRipper 可以并排显示板图和 PDF 原理图。点击标题展开说明，按 **?** 查看快捷键。

<!-- docker-only -->
## 使用 Docker 运行

可在 NAS 或电脑上使用 Docker 部署，扫描挂载目录并建立资料库。

- **`/library`**：挂载板图目录，可使用只读方式。子目录显示为资料库分组。
- **`/data`**：需可写，用于保存拖入的文件和持久数据。
- 用浏览器打开映射端口，首次进入时建立索引。增加文件后，在“设置 ▸ 资料库”点击“立即扫描”，也可启用每次启动时重建索引。
- 可在“设置 ▸ 资料库”配置 WebDAV 或 CopyParty 同步。

<!-- /docker-only -->

## 打开文件

- 将板图拖入窗口，或点击顶部的 **打开** 按钮。可以同时选择板图和 PDF 原理图。
- 支持 `.bvr` / `.bv`、`.brd`（OpenBoardView、Cadence Allegro、EAGLE）、`.bdv` / `.asc`、`.fz` / `.cae`、`.cad`（GenCAD / Mentor Neutral）、`.pcb`（XZZ）、`.tvw`、`.PcbDoc` 和 `.kicad_pcb` 等格式。
- **`.pcb` 在这里指 XZZ 板图，不能直接打开 PADS 二进制 PCB。OrCAD `.dsn` 也不支持，原理图请使用 PDF。**
- 手机或平板无法拖放时，使用“打开”按钮选择文件。
- **Ctrl / ⌘ + O** 和 **Ctrl / ⌘ + P** 均可打开文件选择窗口。
- 文件由本机解析，离线单文件版无需安装或联网。

<!-- docker-only -->
## 资料库

- **板号**：按板号和设备型号分组，内容相同的文件合并显示。
- **PDF 搜索**：搜索已建立文本索引的原理图。可将常用图纸标为参考图纸。
- **文件夹**：按目录浏览。桌面版可选择本地资料库文件夹。
- 文件索引先扫描板图和 PDF；PDF 文本索引随后在后台运行。
- 自动关联可按同名、板号、近似文件名或目录中唯一 PDF 进行匹配。在“设置 ▸ 资料库”预览和调整规则。

<!-- /docker-only -->

## 关联板图与原理图

- 点击板图或 PDF 标签页的 **∞** 按钮建立关联。
- 关联后，点击板图中的元件可以在 PDF 中定位；板图工具栏的 **PDF 联动** 按钮用于开关此功能。
- 两份 PDF 也可关联，以位号为线索在图纸之间查找。

## 查看板图

- **信息** 显示选中元件的引脚、网络和属性；**图层** 控制元件、走线、过孔、丝印及覆铜的显示。
- 点击元件或引脚高亮网络；可在 **搜索** 中按位号或网络名查找。
- **正反面对照** 同时显示正反面；**背面元件轮廓** 用于查看另一面的元件位置。
- 右键元件可以复制位号、隐藏、置于底层、在 PDF 中搜索或加入工作清单。
- **Shift + 点击** 将元件加入工作清单，可记录检修备注和测量值并导出。
- 支持多个标签页；拖动标签可分栏对照。

## 平移、缩放与快捷键

- 拖动和滚轮用于平移、缩放。可在首页“快速设置”或“设置 ▸ 输入”调整操作方式，也可使用手势引导设置。
- 双指捏合始终缩放；空格键切换正反面。
- **W / A / S / D** 平移，**Q / E** 旋转 90°，**Shift + W / S** 缩放。
- **`~`** 切换资料库侧栏，**?** 打开完整快捷键列表。
- PDF 中可旋转、镜像和切换单页／连续滚动；**Q / E** 旋转，**Ctrl / ⌘ + ↑** 镜像。
- AZERTY 键盘按键盘位置对应快捷键。

## 界面语言与显示

- 顶部语言框可在 **简体中文** 与 **English** 之间切换。切换后重新加载，语言选择保存在本机。
- 文件名、元件位号、网络名、用户备注保持原文。
- “设置 ▸ 主题”可调整板图和引脚颜色；“设置 ▸ 渲染”可调整画质与性能。
- “设置 ▸ PDF”可过滤图纸水印。外部发布说明、原始文件内的说明和诊断细节保留原文。
